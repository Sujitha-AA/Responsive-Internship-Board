# Responsive Internship Board

An accessible, responsive internship listing interface built with vanilla HTML, CSS, and JavaScript (no frameworks).

## 🚀 Live Preview
- **Live URL:** [Insert your GitHub Pages or Vercel link here]

## ✨ Features
- **Semantic HTML & Accessibility:** Uses proper landmarks (`<header>`, `<main>`, `<section>`), explicit form labels, and clear keyboard focus states.
- **Responsive Layout:** Mobile-first CSS layout scaling smoothly across mobile (~360px), tablet (~768px), and desktop viewports using CSS Grid and Flexbox.
- **Dynamic Search & Filtering:** Filter listings instantly by keywords (role/company) or specific domains (Engineering, Design, Product, Data).
- **Empty States:** Gracefully handles zero-result searches with a clean empty state message.

## 🛠️ Built With
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (DOM manipulation, event listeners)

## 📱 Responsive Testing Results
- **Mobile (360px):** Single-column stacked card layout with accessible touch targets.
- **Tablet (768px):** 2-column grid layout with side-by-side search and filter controls.
- **Desktop (1024px+):** 3-column grid layout with hover transitions and optimized spacing.

## 🏃‍♂️ How to Run Locally
1. Clone this repository or download the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` directly in your browser, or use the **Live Server** extension for local development.
